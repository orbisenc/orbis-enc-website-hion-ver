# 후속 작업 목록

## P1

- Prisma 저장소를 모든 시연 Route Handler에 연결하고 Serializable 트랜잭션·행 잠금을 운영 DB에서 검증
- 실제 TOTP 등록·복구, 계정 잠금, 역할별 세분 권한 UI
- 관리비 계획 대비 예산의 편성·버전·승인 UI와 연도별 예산 API
- 장기 미납 심화 분석과 규칙별 알림 설정
- 외부 관리사무소 회계 시스템 직접 API 연동과 작업 큐
- 본인 세대 관리비 명세 주민 조회, 개별 명세 PDF와 알림 발송
- 관리비 CSV 사용자 정의 열 연결 규칙 저장과 공급자별 프리셋
- GLB/glTF 업로드·권한 URL, 카메라·핫스폿 편집 영속화, HLS·WebVTT 실제 자산
- 한국어 글꼴을 포함한 PDF 생성과 식별 자료 내보내기 사유·감사 이벤트
- 실제 알림·본인확인 공급자, S3 호환 저장소, 악성 파일 검사 연동
- 법률 검토 후 `LEGAL_CONSENT` 전자서명 수직 기능

## P2

- 공동소유·대리 의결권 검증, 익명 캠페인의 분리형 증거 보관
- 대규모 발송 작업 큐와 공급자 웹훅, 접근성 자동 회귀와 다중 브라우저 시각 기준선
- 운영 관측성, 재해 복구 자동화, 데이터 보존 만료 승인 작업
